## Project structure

- `app.py` — Flask app
- `templates/index.html` — portfolio page + SEO + Person structured data
- `static/css/style.css` — responsive design
- `static/js/script.js` — navigation + WhatsApp message form
- `static/images/profile.png` — uploaded profile photo
- `static/certificates/` — uploaded certificates
- `requirements.txt`
- `vercel.json`

## Before deployment

1. Replace `YOUR-DOMAIN.com` in `index.html` with your real domain.
2. Replace `YOUR-GITHUB-USERNAME` with the real GitHub username/profile URL.
3. Review the project cards and replace them with your actual repositories.
4. For Google Search Console, submit your final domain and `sitemap.xml`.
5. Add a real `sitemap.xml` and `robots.txt` at the site root before production indexing.

## Run locally

```bash
pip install -r requirements.txt
python app.py
```

Open `http://127.0.0.1:5000/`.
